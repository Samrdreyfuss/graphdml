## The cost of the focal set

100 seeds, default learners. Using all nodes (no focal set) lowers RMSE substantially, but its i.i.d. variance ignores dependence between neighbors' scores, so for most effects the standard errors are too small (se_over_sd < 1) and coverage falls below nominal. Closing this gap with a dependence-robust variance and cluster cross-fitting is the top V1.1 item.
