# Example datasets
Every dataset is a `GraphDataset` with the data, the true effects (where known) and a story
card: `print(ds.DESCR)`. Five generate their data offline; `make_lastfm_promo` downloads a
public network on first use; `load_insurance_experiment` needs a free download.
